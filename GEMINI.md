# Project Context: Nightwave

A web-based project (Nightwave) consisting of HTML, CSS, and JavaScript, featuring a custom "Bean" character and associated branding.

## Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript.
- **Assets:** Custom PNG imagery located in the `images/` directory.

## Engineering Standards
- **Styling:** Use Vanilla CSS in `style.css`. Maintain the existing aesthetic centered around the Nightwave/Bean branding.
- **Scripting:** Keep logic in `script.js`. Focus on clean, modular Vanilla JS.
- **Assets:** Reference images from the `images/` directory using relative paths.
